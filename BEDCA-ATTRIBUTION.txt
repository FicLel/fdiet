bedca_foods.csv — attribution and terms of use
==============================================

Source: AESAN/BEDCA Base de Datos Española de Composición de Alimentos v1.0 (2010)

The file `bedca_foods.csv` in this repository is a copy of `output/bedca_foods.csv`
from https://github.com/TerjeRu/bedca-database, a retrieval of the Spanish Food
Composition Database (https://www.bedca.net/) made in August 2026 through its
public XML query interface. 957 foods, one row each, values per 100 g of edible
portion.

Terms, per the AESAN/BEDCA conditions of use:

  * The attribution line above must accompany any reproduction or publication
    of this data, INCLUDING IN APPLICATION CREDITS. Any screen of fdiet that
    shows these figures has to carry it.
  * The data may not be modified, nor its original meaning altered. Every value
    is therefore stored verbatim in `bedca_foods` — no rounding, no unit
    conversion, no normalisation. Each nutrient keeps the unit it was published
    with, which is why the table has a `*_unit` column beside every value.
    Energy is in kJ for 947 of the 957 foods and kcal for 8.
    Figures derived for display (kcal from kJ, a portion scaled from the
    per-100 g value) are computed at read time and never written back.
  * Use is limited to personal, educational or NON-COMMERCIAL purposes.
    Reproduction, translation or any other use in electronic format requires
    the express authorisation of AESAN/BEDCA. If fdiet is ever run
    commercially, that authorisation has to be obtained first.
  * Errors in the data should be reported to bedca.adm@gmail.com.
